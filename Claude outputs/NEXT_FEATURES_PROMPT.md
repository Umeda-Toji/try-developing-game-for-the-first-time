## 1. 決まっていること（11/19 に私が決めた）

### 1.1 設定画面（音量・感度など）
- 入れる項目：
  - **音量を種類ごとに**：全体・BGM・効果音・環境音
  - **感度を分ける**：マウスとパッド、ふつうのときと構えて（アイサイトで）狙っているときを、それぞれ別に
  - **カメラの反転**：上下の反転・左右の反転
  - **狙いの補助**：パッドで構えたとき、照準が敵に少し吸い付く（オン／オフ）
- ❓ 次の点は案を出して確認する
  - 設定画面をどこから開くか（ポーズメニューだけか、タイトルからも開けるか）
  - 保存先（今の画質の設定と同じ `user://settings.cfg` にまとめてよいか）
  - 感度・音量の最小値・最大値・最初の値、狙いの補助の強さ・最初はオンかオフか

### 1.2 ロックオンの切り替え
- ロックオン中に**ロックオンボタン（Tab／ホイールクリック／L2）をもう一度押すと、次の敵に切り替わる**
- **長押しで解除**する（今は「もう一度押すと解除」なので、ここが変わる）
- ❓ 次の点は案を出して確認する
  - 「次の敵」をどの順番で選ぶか（画面の中央に近い順、距離が近い順、など）
  - 長押しと判定するフレーム数
  - 敵が1体しかいないときに押したらどうなるか

### 1.3 敵（苗人）の花
- **顔の代わりに、頭に大きな花**を付ける（`docs/WORLD.md` の「もう顔はない」「攻撃の直前に体の花を開く」に合わせる）
- 合図の仕方：**普段はつぼみ。攻撃の予兆で開き、白（パリィできる）か赤（パリィできない＝棘咲き）に咲く**
- **今の合図（体が光る・まわりを照らす赤い光 E-15）も残す**
- ❓ 次の点は案を出して確認する
  - 花の作り方（コードで形を作るか、CC0 のモデルを使うか。使うなら候補）
  - フェイント攻撃（E-10）のニセの光のとき、花はどう動くか
  - 攻撃のあと花を閉じるか、どのくらいで閉じるか
  - ボス（母株）・重装兵・双剣士・魔法使いも同じ花か、形や大きさを変えるか（設定では、ボスは「深く傷つくと全身が咲く」＝第2形態）
  - 倒したときの花の見た目（しおれる、散る、など）

### 1.4 探索中の静かな曲・環境音・敵が光るときの音
- 次の音を足す：
  - **探索中の静かな曲**（今は起動するとすぐ戦闘曲が流れている）
  - **環境音**（例：風・鳥・水など）
  - **敵が光る（花が開く）ときの音**
- **素材は、あなた（Claude Code）が CC0 の候補を探して出す。** 曲名・作者・URL・ライセンス・長さを報告し、私が聴いて選んでから使う
- 環境音は、設定画面の「環境音」の音量で変えられるようにする
- ❓ 次の点は案を出して確認する
  - 探索の曲と戦闘の曲を、いつ・どうやって切り替えるか（敵に気づかれたら、など）
  - 環境音を場所ごとに変えるか（水路の近くは水の音、など）
  - 光るときの音を白（パリィできる）と赤（パリィできない）で変えるか

### 1.5 起伏のある地面
- **大きな起伏（丘・くぼ地・坂）も入れる**
- **止まり時計の広場・旧市民ホールにも起伏を入れる**（どこも平らではなくなる）
- ❓ 次の点は案を出して確認する（ここは影響が大きいので、特に丁寧に）
  - 起伏の作り方（Godot 4.7.2 の高さの地図のような仕組みを使うか、など）と、内蔵GPUでの重さ
  - 起伏の高さ・坂の最大の角度、プレイヤーと敵が登れる坂の角度
  - 建物・車・看板・木・アイテム・記録の断片・見晴らしの塔などを、起伏の上にどう置き直すか
  - 道や川・水路・高架・本棚など、今の移動の場所（W-04）をどう残すか
  - 坂の上での戦い：攻撃の当たり判定、敵の動き、魔法使いの弾、回避、パリィに問題が出ないか
  - セーブの「最後に立っていた場所」（S-01）が、地形が変わった後も正しく使えるか
  - 自動テストの部屋（20m四方）は平らのままでよいか

### 1.6 銃
- **主人公が銃を撃つ。** 銃は**補助（弱め）**。剣のパリィ中心の遊びを崩さない
- 銃は3種類：**AR（アサルトライフル）・SMG（サブマシンガン）・SG（ショットガン）**
- **ボタンで剣と持ち替える。銃を持っている間はパリィできない**
- 撃ち方は2種類：
  - **腰だめ撃ち**（構えずに撃つ）
  - **アイサイト**（構えて照準をのぞいて撃つ）
- **撃ったときの反動（リコイル）** と **リロード** を入れる
- **予備の弾には限りがあり、街で拾う**
- 操作：

| 操作 | キーボード・マウス | パッド（PlayStation表記） |
|---|---|---|
| 剣に持ち替える | F | 武器の輪で選ぶ |
| AR に持ち替える | 1 | 武器の輪で選ぶ |
| SMG に持ち替える | 2 | 武器の輪で選ぶ |
| SG に持ち替える | 3 | 武器の輪で選ぶ |
| 武器の輪を開く（剣のとき） | — | R3（右スティック押し込み） |
| 武器の輪を開く（銃のとき） | — | △長押し |
| 構える（アイサイト） | 右クリック（銃のときだけ） | L1 |
| 撃つ | 左クリック（銃のときだけ） | R1 |
| リロード | R | ○ |

  - 剣のときは、右クリック・左クリック・△は今までどおり剣の攻撃（パリィ）。**剣のときの△は、長押しで輪を開かない**（パリィの受付がずれないように）
  - R は、遊んでいる間はリロード、結果画面では今までどおりリトライ
- 世界観：**銃の設定は、`docs/WORLD.md` に足す文章の案をあなたが出し、私が選ぶ**。私が選ぶまで WORLD.md は変えない
- ❓ 次の点は案を出して確認する
  - 3種類それぞれの違い（ダメージ・連射の速さ・弾倉の弾数・予備の弾の上限・反動・弾の広がり・届く距離・リロードの長さ）。数値はすべて物理フレームで
  - 銃のダメージで敵の体幹を削るか（補助なので削らない案も含めて）
  - 予備の弾を3種類で共通にするか、種類ごとに分けるか。どこで・どれだけ拾えるか（街のどこに置くか、敵が落とすか）。拾った弾はセーブに残すか
  - 武器の輪を開いている間、ゲームを止めるか・遅くするか・そのまま動くか。輪の中をどのスティックで選ぶか（R3 を押しながら右スティックは操作しにくいかもしれない）
  - 腰だめ撃ちのときに、どこを狙うか（画面の中央、ロックオン中の敵、など）
  - アイサイトのときのカメラ（一人称に近づけるか）と、狙いの補助の効き方
  - 持ち替えにかかるフレーム数。持ち替え中・リロード中・構え中に、回避・ジャンプ・走る・滑空・壁のぼり・泳ぎができるか
  - 魔法使いの弾（胞子玉）を撃ち落とせるか
  - 弾が壁を通り抜けないこと（魔法使いの弾と同じように調べる）
  - 銃と照準・弾の数の表示（画面のどこに出すか）
  - 銃のモデル（CC0 の候補を出す。コードで作る案も）と、撃つ音・リロードの音・弾切れの音（CC0 の候補を出す）
  - パッドの L1・R1・○・R3 が、今ほかの操作に使われていないかの確認
